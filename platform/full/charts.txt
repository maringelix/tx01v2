# versions, archive SHA256 and image digests as the local lab (platform/local/versions.env, and
# platform/versions.env for the Collector): the cloud changes values, never versions. Read by
# platform/install.sh and by the harness (checks helm-template-full and platform-sizing).
#
# <repo key> <version key> <sha256 key> <chart> <release> <namespace> <values files under platform/>
#
# The values files are applied in order, comma separated: the base of the local lab (the sizes, the
# probes of the images, the security contexts) first and the overlay of the cloud after it
# (platform/values/full). The Collector has no local base: its base is the cloud values of the core
# profile, which the full profile only extends (Tempo and the spanmetrics next to X-Ray).
